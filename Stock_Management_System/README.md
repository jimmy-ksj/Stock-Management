# Stock Management System

Full-stack inventory/stock management system.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT + bcrypt
- Icons: lucide-react

## Run Backend
```bash
cd backend
npm install
npm start
```

Create/import `database.sql` in MySQL first.

## Run Frontend
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173
